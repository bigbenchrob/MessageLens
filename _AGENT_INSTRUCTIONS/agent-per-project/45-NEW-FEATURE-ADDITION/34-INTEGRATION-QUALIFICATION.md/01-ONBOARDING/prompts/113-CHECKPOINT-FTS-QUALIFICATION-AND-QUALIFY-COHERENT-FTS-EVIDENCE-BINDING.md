The six FTS dimensions remain independent:

1. Schema/runtime compatibility.
2. Content material equivalence.
3. Bounded raw MATCH corpus equivalence.
4. Bounded production-search corpus equivalence.
5. Qualified internal-index evidence.
6. Exhaustive FTS semantic equivalence.

Preserve all TRUE/FALSE/UNKNOWN and assessed/unassessed values precisely. In particular, (5) and (6) remain **UNKNOWN and unassessed** even if (1)–(4) are TRUE. Do not present a partially qualified FTS result as overall reconstruction TRUE or “no problems found.”

A stable content mismatch does not by itself prove internal postings differ. A raw search mismatch that is masked by tags or limits remains raw FALSE even if production corpus is TRUE. A production search mismatch caused by overlay-only drift must not be relabeled an FTS posting failure. Unstable interval evidence cannot assert either a contradiction or success, even if an attempt's local comparison reported one. A known contradiction inside an *accepted* interval remains FALSE beside other UNKNOWN dimensions. Missing runtime identity, failed query, budget exhaustion, cancellation, unsuccessful cleanup or changed source identity must be explicitly classified as UNKNOWN at the correct dimension/binding, never as an empty result.

**Important policy consequence:** exhaustive FTS proof remains unavailable under these contracts. This task must not weaken a future destructive eligibility predicate to accept four finite-TRUE dimensions instead of the required stronger proof. Any design that would imply authorization must stop.
